# GridPulse — Open-Source Power Systems, Protection & HVDC Lab

Static site for GitHub Pages: technical articles plus interactive, in-browser engineering simulators.

| Path | What it is |
|---|---|
| `index.html` | Home: articles, tutorials, interactive lab (Vd–Id, IDMT, VSC P-Q, Mho), OSS tools, contact |
| `hvdc-controls.html` | **HVDC Controller Lab** — LCC pole control (CC/CEA, VDCOL, mode shift, commutation failure, DC-fault restart), current-loop Bode tuning, commutation margin, reactive-power & filter switching, VSC dq & DC-voltage control, Python workbench (Pyodide) |
| `assets/js/hvdc-models.js` | Dependency-free controller models (also runs in Node.js) |
| `assets/js/hvdc-lab.js` | Lab UI: charts, presets, share links, CSV export, embeds |
| `_posts/` | **Articles** (Markdown). See [PUBLISHING.md](PUBLISHING.md) |
| `_layouts/post.html`, `_includes/sim.html` | Article page layout and the simulator-embed include |
| `articles.json` | Generated by Jekyll — the home page reads it to list articles |
| `admin/` | Author Studio (Sveltia CMS) for writing articles in the browser |

Open-source stack: Jekyll · Tailwind CSS · Chart.js · KaTeX · Lucide · Pyodide · Sveltia CMS.
Models are educational average-value representations — validate designs with EMT tools.
